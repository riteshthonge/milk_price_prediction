# Dairy Intelligence Dashboard

An AI-powered dairy price forecasting platform designed to analyze and visualize future dairy market trends using Machine Learning and RBI food inflation insights. The system focuses on predictive analytics for dairy products such as milk, dahi, ghee, butter, and paneer using time-series forecasting models trained on historical pricing data. 

---

# 1. Features

* Machine Learning-based dairy price forecasting using Prophet Time-Series Models
* Forecast generation for:

  * Full Cream Milk
  * Toned Milk
  * Dahi
  * Ghee
  * Butter
  * Paneer
* Interactive analytics dashboard with:

  * Price Trend Graphs
  * Price Comparison Charts
  * Forecast Tables
  * KPI Metrics
* RBI food inflation outlook integration alongside ML predictions
* Real-time 6-month forecast generation
* Responsive UI built with React and Tailwind CSS
* Independent forecasting models trained for each product
* Historical data collection incorporating:

  * Seasonal fluctuations
  * Market trends
  * Demand corrections
  * Inflation-based pricing patterns

---

# 2. Machine Learning Model

The project uses **Prophet by Meta** for time-series forecasting.

Each dairy product is trained as an independent forecasting model using historical monthly pricing datasets. The model learns:

* Long-term market trends
* Seasonal behavior
* Price fluctuations
* Market stabilization patterns

The forecasting pipeline combines:

* Historical dairy pricing data
* Trend analysis
* Seasonality detection
* RBI inflation outlook visualization

to generate intelligent forecasting insights.

# 5. Installation & Setup

## Clone Repository

```bash
git clone <your-repo-url>
cd <project-folder>
```

## Setup ML API

Install dependencies:

```bash
pip install fastapi uvicorn prophet pandas
```

Run server:

```bash
python -m uvicorn main:app --reload
```

Server URL:

```txt
http://127.0.0.1:8000
```

## Run Frontend

Open:

```txt
index.html
```

OR run a local server:

```bash
python -m http.server 5500
```

Then visit:

```txt
http://localhost:5500
```

# 6. Model Limitations & Improvements

Current forecasting accuracy depends heavily on the quality and quantity of historical pricing data. Since the system primarily uses historical time-series patterns, future improvements can include:

* Collection of larger real-world dairy pricing datasets
* Integration of live market pricing APIs
* Better inflation and demand indicators
* Inclusion of festival and seasonal demand events
* Advanced multivariable forecasting models
* Real-time dairy market analytics

These enhancements can significantly improve robustness and forecasting accuracy.
